# Política de segurança

Este projeto está em pré-lançamento e não deve receber dados reais.

Não publique vulnerabilidades, credenciais, dados de saúde ou provas exploráveis
em issues. Use o formulário privado **Security → Report a vulnerability** do
GitHub quando estiver disponível; caso contrário, contacte o proprietário pelo
perfil verificado apenas para combinar um canal seguro.

As garantias implementadas e os gates ainda obrigatórios estão documentados em
[docs/SECURITY.md](docs/SECURITY.md) e
[docs/runbooks/RELEASE_GATE.md](docs/runbooks/RELEASE_GATE.md).
